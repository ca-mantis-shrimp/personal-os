# Inactive ParticleOS examples

These files were moved out of active mkosi discovery when Personal OS became a
Fedora-only headless fork. They preserve upstream implementation context and
licensing; they are not another plan, release channel or supported build recipe.
The canonical decisions and handoff remain in `.clearhead/charters/mini-server.md`
at the repository root.

Retained material includes desktop/other-distro/OBS profiles, network ESP examples,
all eight original extra UKI profiles, the upstream demo homed credential, OBS
workflow and TODO, and the optional OpenSC module. Relative symlinks were preserved.
The demo access and reset/public-storage boot modes are deliberately NOT shipped.
Do not copy this tree into an image or run its installation/reset examples.

The active root still uses ParticleOS-derived repart, UKI/verity and sysupdate
machinery, with fork-owned packages, branding and headless policy. See the root
README and `docs/PARTICLEOS-UPSTREAM.md` for provenance and current limitations.
