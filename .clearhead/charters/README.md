# Personal OS

Maintain a purpose-built ParticleOS-derived OS with a pinned chezmoi submodule.
It runs the dev pod (devbox, installed 2026-10-11 on the old mini-travel-server
hardware) and will run the N150 [services](services.md) machine; the closed
mini-server charter, archived in [../archive](../archive/01a0fb15-b777-75a3-a048-7e0da5722a02.md), holds the earlier plan. Keep generic OS lifecycle and profile integration here, user
configuration in `dotfiles/`, and custom ClearHead release work in platform.

This is an initial local fork, not a deployed image or a public release.
