# Personal OS

Maintain a purpose-built ParticleOS-derived OS with a pinned chezmoi submodule.
The first consumer is `mini-travel-server`; its canonical decisions, approvals
and next-agent handoff are in [mini-server.md](mini-server.md) and the paired
actions. Keep generic OS lifecycle and profile integration here, user
configuration in `dotfiles/`, and custom ClearHead release work in platform.

This is an initial local fork, not a deployed image or a public release.
